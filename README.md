# Lucent · 轻玻璃新标签页

一个纯前端、零依赖的自定义浏览器新标签页：**真实照片壁纸 + 轻玻璃（液态玻璃）质感**，集导航、搜索、时钟、天气、待办、便签、环境音于一体。

> **设计方向：宣纸 · 案头。** 真实照片壁纸（Unsplash）先经降饱和 + 压亮度退为「氛围」，再由方向性蒙版收拢视线；界面分**两级表面**——内容面板近实心求清晰，浮层（搜索/菜单/弹窗）用真玻璃求通透。默认电脑版，并已做响应式适配手机。

## ✨ 特性

- 🔎 **搜索框**：12 个搜索引擎一键切换，支持 `/算式` 直接计算（如 `/23*7+5`）
- 🧭 **导航分组**：动态分组、真实 favicon、组内拖拽排序
- 🕐 **实时时钟**（可选显示秒）+ 每日一句
- 🌤 **天气**：[Open-Meteo](https://open-meteo.com) 免费免密钥（当前 / 多日预报 + 城市搜索 + AQI 空气质量）
  - **按网络位置自动定位**：靠出口 IP 判断城市，**不申请定位权限、不弹授权框**，打开新标签页就是本地天气；结果缓存 12 小时（失败只记 10 分钟，网一恢复自动纠正）
  - 四家免费定位服务依次兜底，城市名统一转成中文（`Anyang` → `安阳`）；手动选过城市后永远以手选为准，弹窗里留一键「自动定位」回头路
- ✅ **待办**：增删改
- 📝 **便签**：自动保存
- 🎧 **环境音**：Web Audio 实时合成 白 / 粉 / 棕噪音、雨声、**咖啡馆 / 海浪 / 篝火**（纯本地，无音频文件）
- 🎨 **壁纸**：自然 / 城市 / 极简 / 抽象四类随机照片、**必应每日一图**（按天缓存），或自定义图片；蒙版浓度 明亮 / 标准 / 深沉。换图走双层**交叉溶解**（1.1s 慢溶解 + 极缓微缩放），不再硬切
- 🌓 **主题**：深色（白字）/ 浅色（深字）一键切换，浅色下玻璃转白、蒙版自动改为提亮
- 🧘 **禅模式（Zen）**：按 `Z` 或点角落按钮，进入**单屏专注视图**——下方整块（题记 / 壁纸栏 / 分组 / 工具 / 提示）收拢移出文档流、不可滚动，时钟 + 天气 + 搜索放大并垂直居中，成为唯一焦点；**该状态持久化**——首次开启后，后续新打开的标签页自动进禅模式，直至主动解除才恢复
- ⏱ **番茄钟**：专注 / 休息计时，**一段结束用系统通知 + 轻柔正弦收尾音温柔提醒**（不弹原生 alert）
- 🧩 **卡片自由拖拽**：分组卡片与待办 / 便签 / 环境音可跨区域拖放排序，顺序自动记住
- 🪟 **统一弹层**：全站零原生 `prompt / confirm / alert`——加链接、建分组、改名、删分组、自定义壁纸、清空数据，一律走同一套居中玻璃面板
- ⌨️ **快捷键**：`/` 聚焦搜索、`↑↓` 切引擎、`W` 换壁纸、`T` 切主题、`Z` 禅模式、`?` 帮助、`Esc` 关弹窗
- 💾 数据存 `localStorage`，支持 JSON 导出 / 导入备份

## 🎨 设计系统

外观全部由 `style.css` 顶部的 CSS 变量驱动，改一处即可整体换肤。

**两级表面（解决「一片灰玻璃浮在照片上」的廉价感）**

| 层级 | 类名 | 用于 | 做法 |
| --- | --- | --- | --- |
| Tier A 面板 | `.panel` | 分组 / 待办 / 便签 / 环境音 / 番茄钟 / 日历 / 倒计时 | 近实心底色 + 细描边，清晰锐利 |
| Tier B 浮层 | `.glass` | 搜索框 / 引擎菜单 / 弹窗 / 天气详情 | 深底真玻璃，白字对比度达标 |

**色板（中国风传统色，均为语义令牌）**

| 令牌 | 深色 | 浅色 | 用途 |
| --- | --- | --- | --- |
| `--accent` | 青瓷青 `#57a99c` | `#3d7d70` | 点睛强调、焦点环 |
| `--success` | 竹青绿 `#73a471` | `#557a45` | 完成 / 播放中 |
| `--danger` | 胭脂红 `#c0504d` | `#a23b36` | 删除 / 危险 |
| `--warning` | 赭石黄 `#c8913c` | `#96681f` | 编辑悬停 |

**其它**

- **壁纸处理**：`--wall-desat` / `--wall-dim` 用 `background-blend-mode` 完成降饱和与压暗（不用 `filter`，少一层合成层）。照片淡出为氛围，UI 才有立足之地。
- **字号标尺**：`--fs-1 … --fs-11` 单调递增；全文件零字面 `font-size`。
- **图标**：`index.html` 内联 `<symbol>` 精灵，统一 1.6px 线性描边，无 emoji。
- **无障碍**：WCAG AA 对比度、`:focus-visible` 焦点环、图标按钮 `aria-label`、键盘可达、尊重 `prefers-reduced-motion`。
- **弹层节奏**：对话框与天气详情共用同一套缓动与时长（进 `.26s` 上浮、出 `.2s` 溶解），**无回弹**；关闭时随蒙版一同柔和退场，不再「啪一下消失」。缩放走独立的 `scale` / `translate` 属性，不写 `transform`（避免覆盖居中用的 `translateX(-50%)`）。
- **高级感＝克制**：全站只保留少数几处动效——整页**静默入场**（纯透明度沉降）、时钟一档极轻的**「墨晕」**（模糊 4px→0）、弹层柔和进退、引擎名下一根 1px **「墨痕」**。一律 ease-out、无回弹、去发光；强调只靠**墨色浓淡 + 一根发丝线**，不靠 glow / 大投影。悬停只提亮描边与纸色，不位移、不发光。
- **质感细节**：正文选区用青瓷青（`::selection`）替换系统蓝；但**输入框内选中文字用极淡中性灰**（`--sel-field`），编辑态安静、不抢戏，不出现「彩色选块」；**搜索框聚焦不套强调色描边**（文本框自带光标，绿框纯属多余）；正文 `antialiased` 字体平滑；主题化细滚动条（设置 / 便签 / 待办 / 引擎菜单 / 倒计时）；时钟 · 番茄钟 · 倒计时 · 日历数字 `tabular-nums` 对齐不抖；输入框焦点环补盲（`range` / `date` / `number`），键盘可达性兜底。
- **右上角工具条**：壁纸 / 明暗 / 禅模式 / 设置四枚图标收进一条**玻璃胶囊**（`backdrop-filter` 毛玻璃 + 发丝描边），成组待在右上角，不再松散堆砌；禅模式与明暗按钮图标明显区分（同心圆「聚焦」vs 月牙），开启时禅按钮以青瓷青点出「正启用」。**进入禅模式时胶囊向右收拢缩成一枚圆钮**（其余按钮宽度收零、间隙归零），只裹住青瓷青同心圆。

**统一弹层（`.dialog`）**

原生 `prompt / confirm` 被浏览器钉在窗口顶部、样式不可控，还一次只能问一个问题（加一条书签要弹两次）。本项目用一套居中玻璃面板全部接管：

- `openDialog(opt)` → Promise 解析为 `{ 字段名: 值 }`，取消得 `null`；`confirmDialog(opt)` → Promise\<boolean\>。
- 字段是结构化表单：`required` 与自定义 `validate` **就地报错**（标红 + 焦点送到出错项），不做全局 alert。
- 危险操作（删分组 / 清空数据）主按钮转胭脂红，图标转警示。
- 焦点陷阱（Tab 在面板内循环）、`Esc` 关闭（捕获阶段注册，先于全局快捷键）、关闭后焦点归还原元素。
- `footLeft` 放次要动作（如自定义壁纸的「从本机选择」），`onAction(act, close)` 钩子处理自定义按钮。

## 🚀 安装（作为浏览器扩展，推荐）

1. 浏览器地址栏打开 `chrome://extensions`（Edge 用 `edge://extensions`）
2. 右上角开启「**开发者模式**」
3. 点击「**加载已解压的扩展程序**」→ 选择本项目文件夹
4. 此后打开新标签页即为 Lucent

> 也可本地预览：在本目录运行 `python -m http.server 8123`，浏览器访问 `http://localhost:8123/`。

**权限说明**：清单里 `permissions` 为空数组——不申请定位、不申请标签页、不申请存储（数据只写在本页 `localStorage`）。仅声明天气与定位服务所需的 `host_permissions`，所有数据都直连 Open-Meteo，不经任何第三方服务器。

## 📦 自动构建与发版

仓库已配置 GitHub Actions（`.github/workflows/release.yml`），无需手动打包：

- **每次推送 `main`**：自动构建扩展压缩包并作为 Artifact 上传，仓库 Actions 页可随时下载最新构件。
- **打版本标签（如 `v1.2.0`）**：自动创建 GitHub Release，附带 `lucent-newtab-vX.Y.Z.zip` 与自动更新日志。

本地发版步骤：

```bash
# 1. 改完代码后，修改 manifest.json 里的 version
# 2. 提交
git add -A && git commit -m "feat: ..."
# 3. 打标签并推送（推送标签会触发自动 Release）
git tag v1.2.0 && git push && git push --tags
```

本地手动打包（可选）：

```bash
python scripts/build.py        # 产物：dist/lucent-newtab-v<version>.zip
```
